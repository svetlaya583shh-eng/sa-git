# Правила именования

docs/<фамилия>-request-data — ветка для документа на запрос данных;

fix/<фамилия>-<краткое-описание> — исправление опечатки или формулировки;

feat/<фамилия>-<краткое-описание> — добавление нового раздела или шаблона.

Пример: docs/ivanov-request-customer-orders

Новая строка от Аркадия
